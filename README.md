# Shadowrocket Rules & Modules Mirror

本项目为 [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script) 的 `rule/Shadowrocket` 基础规则镜像库，同时提供个人自定义拓展模块。

---

## 规则来源与同步说明

- **基础规则来源**：`blackmatrix7/ios_rule_script` 官方仓库的 `rule/Shadowrocket` 目录。
- **同步机制**：GitHub Actions 每 6 小时自动拉取并更新上游规则。
- **使用说明**：本镜像库同步的是上游的 `.list` 规则文件，非完整配置文件（`.conf`）。
